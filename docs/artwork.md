# Icon artwork

The app icon was generated with the built-in OpenAI image generation tool and packaged as a macOS `.icns` file. The original PNG is [app-icon.png](app-icon.png). `scripts/make-icon.sh` creates the icon sizes with native macOS tools.

Prompt: an original macOS app icon for Extract IPs; a matte deep teal rounded-square tile, transparent margin, and a bold warm ivory glyph showing three rounded nodes converging into one output node. Front-on composition, subtle enamel depth, legible at small sizes. No text, numerals, shield, lock, globe, neon, or watermark.
